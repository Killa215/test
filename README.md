# 💬 Корпоративный мессенджер

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![React](https://img.shields.io/badge/React-18.2-61DAFB?logo=react)](https://reactjs.org/)
[![Vite](https://img.shields.io/badge/Vite-4.0-646CFF?logo=vite)](https://vitejs.dev/)

Веб-приложение для общения внутри команды с поддержкой личных и групповых чатов. Реализовано на основе стартового шаблона Lama Dev с использованием современных инструментов.

![Скриншот чата](https://i.yapx.ru/eG9B6.png))

## ✨ Особенности

- **Авторизация и регистрация** — безопасный вход и создание аккаунта.
- **Личные сообщения (1-1 диалоги)** — общение напрямую с коллегой.
- **Групповые чаты** — создание групп и добавление участников.
- **Статус "онлайн/офлайн"** — видимость присутствия пользователей в реальном времени.
- **История сообщений** — сохранение и отображение переписки.

## 🚀 Быстрый старт

Эти инструкции помогут вам запустить копию проекта на вашем локальном компьютере для разработки и тестирования.

### 📋 Предварительные требования

- **Node.js** (версия 16.x или выше)
- **npm** или **yarn**

### 🔧 Установка и запуск

Выполните следующие команды в терминале:

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/ваш_ник/название_репозитория.git

# 2. Перейдите в папку проекта
cd название_репозитория

# 3. Установите все зависимости
npm install

# 4. Запустите сервер для разработки
npm run dev
```

### 🛠️ Стек технологий
В проекте использованы следующие ключевые технологии:
Frontend: React (функциональные компоненты + хуки), JavaScript (ES6+)
Сборка: Vite — быстрый инструмент сборки
Стилизация: CSS3 с адаптивной версткой
Сеть: REST API / Axios, WebSocket (для обмена сообщениями в реальном времени)
База данных (предположительно): Firebase (судя по файлу cors.json и структуре)
